# Publish Ithaca Bound on GitHub Pages

This static site requires no build step. Keep the HTML, CSS, JavaScript, images, and fonts in the repository root. All paths are relative and support a GitHub Pages project URL.

1. Sign in at https://github.com and open https://github.com/sandeshbasnet804-bit/ithaca-bound. This repository already exists and its default branch is `main`.
2. Upload `index.html`, `destinations.html`, `booking.html`, `style.css`, `script.js`, the `images` folder, and the `fonts` folder. Preserve both folders and the exact capitalization and spaces in filenames. You can unzip `ithaca-bound-github-pages.zip` and drag the extracted contents onto GitHub's **Add file → Upload files** screen. Commit to `main`.
3. In the repository, open **Settings → Pages**. Set **Source** to **Deploy from a branch**, choose `main` and `/(root)`, then save.
4. Wait for the Pages deployment to finish. GitHub displays the published address in **Settings → Pages**, expected to be `https://sandeshbasnet804-bit.github.io/ithaca-bound/`. This address is not verified until deployment succeeds.
5. Open that address and check all three navigation links, images, and headings. On Home, open and submit both activities and reset their results. On Destinations, choose each voyage and confirm it is preselected on Booking. Submit a valid fictional booking, break the envelope seal, and close the letter. Check mobile layout and the browser console for errors.

The booking experience is fictional and runs entirely in the browser. It creates no real reservation. Portraits stay in the browser.

Share the repository or published URL with the assistant for live verification. A predicted URL is not proof that deployment succeeded.
